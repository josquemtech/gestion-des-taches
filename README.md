# 🚀 Gestion des Tâches

Système complet de gestion des tâches avec notifications par email et interface moderne.

## 🎨 Design
- Interface entièrement responsive avec Bootstrap 5.3
- Animations fluides et interactions intuitives
- Thème moderne avec dégradés et ombres portées
- Système de notifications en temps réel

## 🛠️ Configuration requise
- PHP 7.4+
- MySQL 5.7+
- Composer
- MailHog (pour les emails de test)
